# Правила стайлгайда команды — детерминированный слой [styleguide].
#
# Формат — одна строка = одно правило:
#     severity | regex | message
#
#   severity : error | warning | suggestion
#   regex    : шаблон нарушения в ДОБАВЛЕННОЙ строке кода
#              (можно использовать альтернацию `|`, напр. DBI->(connect|prepare))
#   message  : текст комментария, который увидит разработчик в PR
#
# Строки с # и пустые игнорируются. Файл правится заменой на сервере без пересборки.
#
# Ниже — ПРИМЕРЫ. Заменить правилами конкретной команды.

error      | DBI->(connect|prepare|do)\b                | прямой вызов DBI запрещён — используйте корпоративный DAL-wrapper
warning    | \bTODO\b(?!.{0,40}[A-Z]{2,}-\d+)           | TODO без номера тикета (ожидается формат BANK-1234)
suggestion | ^\s*print\b                                | print в коде — для вывода используйте корпоративный логгер
warning    | \buse\s+(?:legacy|Legacy)::                | подключение legacy::* модулей не рекомендуется
suggestion | ^\s*\}\s*$                                 | закрывающий блок должен заканчиваться смайликом :)
