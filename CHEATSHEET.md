# JARVIS — шпаргалка на одну страницу

Полная инструкция: `INSTRUCTION_FOR_DEVS.md`.

---

## Что бот делает

Создал или обновил PR → бот скачал дифф → внутренний ИИ (Феникс) проверил →
через 10–30 сек в PR появились комментарии и сводка.

Бот **только читает код и пишет комментарии**. Не пушит, не мержит, не блокирует
merge. Данные не покидают периметр банка.

---

## Выбрать, что публикуется — строка в ОПИСАНИИ PR

```
@jarvis all
```

Строка должна **начинаться** с `@jarvis`. Регистр не важен, место в описании любое.

| Команда | Публикуется |
|---|---|
| `@jarvis errors` | 🔴 ошибки |
| `@jarvis warnings` | 🔴 + 🟡 *(по умолчанию)* |
| `@jarvis all` | 🔴 + 🟡 + 💡 |

Уровень — порог **«и выше»**: при `warnings` ошибки тоже видны.

Убрать источник целиком:

```
@jarvis all -codestyle
@jarvis warnings -perlcritic -codestyle
```

Источники: `perlcritic`, `codestyle`, `jarvis` (замечания модели).

---

## Три вещи, о которых спрашивают чаще всего

**🔴 Ошибки скрыть нельзя.** Ни порогом, ни минусом. `-codestyle` убирает у
источника предупреждения и подсказки, ошибки — нет.

**Скрытое видно всем.** В сводке всегда строка вида
`**Фильтр:** errors (error). скрыто 12 замечаний.` Ревьюер увидит, что находки были.

**Бот скажет, если не понял команду:**
`Команду «всё» не понял, работаю на уровне warnings.`
Но опечатку в **самой метке** (`@jrvis`) он не заметит — такую строку он просто
не найдёт и отработает на настройках по умолчанию.

## Что-то пошло не так

| Симптом | Что делать |
|---|---|
| бот молчит > 2 мин | сделай ещё один коммит в PR (можно пустой) |
| «Упс! Мой мозг не ответил» | Феникс временно недоступен — повтори позже |
| `✂️ Показана не вся правка` | файл не влез целиком; имена файлов названы в сводке |
| замечание неверное | ИИ ошибается — просто проигнорируй |

Бот — advisory, а не gate. Ревью сеньора он не заменяет.
